# Morningstar-Festivity-render-assistant
Recommended Verified Supported version of blender: 3.6/4.2/5.1, goo-engine supported

Other versions are not tested and verified!!!

For GI characters in PMX and FBX

Advantage:extremely easy to use, support multiple characters

----Guide----

Every button is useful!!

Put the required texture(Lightmaps/ramps) in the tex folder of the characters

Import the character - The addon can only import PMX character, use better FBX if you are using an FBX model

Click all the button in order

It should be done

For certain characters if the shadow is wrong, check its material slot and change its lightmap manually(very rare situation)

Slide bar is for face sdf, slide it to the corresponding charater type.

晨星Festivity渲染助手
推荐已验证支持的 Blender 版本：Blender 3.6 / 4.2 / 5.1

同时支持 Goo Engine。

其他 Blender 版本尚未经过测试与验证！！！

适用于 GI（原神）角色的 PMX 和 FBX 模型。

优点：操作极其简单，并支持多角色。

使用指南

每一个按钮都有用！！

将角色需要的贴图，例如 Lightmap / Ramp，放入角色的 tex 文件夹中。

导入角色。

插件本身目前只能直接导入 PMX 角色。

如果使用 FBX 模型，请使用 Better FBX 进行导入。

按照顺序依次点击插件中的所有按钮。

完成！

极少数情况，如果出现阴影显示错误，请检查对应的 Material Slot（材质槽），并手动修改其 Lightmap。

插件中的滑动条用于调整面部 SDF。请根据对应的角色类型将其调整到合适的位置。

如果有用请点亮星星：）
